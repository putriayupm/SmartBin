# SmartBin Frontend
React + Vite. Berjalan dengan data contoh (mock) sampai backend siap.

    npm install
    npm run dev

Akun contoh (kata sandi: smartbin123): petugas `slamet.riyadi`, operator `hendra.wijaya`.
Saat backend siap: salin `.env.example` ke `.env`, set `VITE_USE_MOCK=false`.
Semua panggilan API ada di `src/api.js`.
